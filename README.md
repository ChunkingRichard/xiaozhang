# 小账 · AI 记账工具

一个完全属于你自己的本地记账应用。**没有订阅、没有付费墙、没有服务器**——数据存你手机里，AI 用你自己的 Key。

---

## 这是什么

针对「不想为记账软件付费，但需要 AI 截图记账 + 智能消费分析」这个需求做的一款可安装到手机的网页应用（PWA）。

它的定位不是复刻任何现成产品，而是一套独立实现的记账工具：界面、图标、交互、代码全部原创。

---

## 怎么打开

### 方式一：电脑上直接打开

双击 `app/index.html` 即可。建议用 Chrome / Edge 打开。

> 注意：直接双击打开时，截图识别和 AI 对话可能因浏览器跨域策略受限。要完整使用 AI 能力，请用方式二。

### 方式二：本地服务器打开（推荐）

在项目根目录执行：

```bash
python -m http.server 8765 --directory app
```

然后浏览器访问 `http://127.0.0.1:8765`

Windows 用户可直接双击 `start.bat`。

### 方式三：部署到 GitHub Pages（电脑手机都能用，强烈推荐）

这是最省事的方案——**免费、不用买服务器、电脑手机同一个网址**。

#### 1. 建仓库

在 GitHub 新建一个仓库，比如叫 `ledger`。

#### 2. 上传文件

把 `app` 目录里的**全部内容**上传到仓库根目录（注意：是 `app` 里面的东西，不是 `app` 这个文件夹本身）。

上传后仓库根目录应该是这样：

```
index.html
manifest.webmanifest
sw.js
.nojekyll
css/
icons/
js/
```



> `.nojekyll` 这个空文件很重要，它阻止 GitHub Pages 的 Jekyll 处理，否则带下划线开头的文件会 404。

#### 3. 开启 Pages

仓库 → **Settings → Pages** → Source 选 `Deploy from a branch` → Branch 选 `main` + `/ (root)` → Save。

等 1~2 分钟，访问 `https://你的用户名.github.io/ledger/` 就能用了。

#### 4. 装到手机

手机浏览器打开上面的网址 → 菜单里选「**添加到主屏幕**」。

桌面会出现图标，点开就是全屏 App（没有浏览器地址栏），**首次打开后支持离线使用**。

> 因为所有路径都用的相对路径，放在 `用户名.github.io/ledger/` 这样的子目录下也能正常工作，不需要改任何代码。

#### 5. 电脑上

直接用 Chrome / Edge 打开同一个网址即可，会自动切换成**桌面版布局**（左侧边栏 + 多栏内容）。

## 关于「手机 App」这件事

你说得对——**本质上它就是个网页**，但通过 PWA 技术可以做到接近原生 App 的体验：

|        | 说明                            |
| ------ | ----------------------------- |
| 添加到主屏幕 | 有独立图标，和普通 App 一样              |
| 全屏运行   | 没有浏览器地址栏和标签栏                  |
| 离线可用   | Service Worker 缓存了界面，断网也能打开记账 |
| 数据本地存储 | 记账数据存在手机本地，不上传                |

**唯一的区别**是：它不是从应用商店下载的。好处是不用审核、不用签名、随时改随时生效。

⚠️ **一个重要的坑**：PWA 的「添加到主屏幕」和「离线缓存」**要求 HTTPS**。GitHub Pages 自带 HTTPS，所以没问题；但如果用局域网 IP（`http://192.168.x.x`）访问，浏览器会限制这些能力。

## 配置 AI（关键一步）

截图识别和 AI 助手都要用到你自己的大模型 API。

进入 **我的 → AI 接口设置**，填写：

| 项目       | 说明           | 示例                          |
| -------- | ------------ | --------------------------- |
| Base URL | 服务商接口地址      | `https://api.openai.com/v1` |
| 模型名称     | **必须支持图片输入** | `gpt-4o`                    |
| API Key  | 你的密钥         | `sk-...`                    |

内置了 OpenAI / DeepSeek / 通义千问 / Kimi / 智谱 的预设，点一下就自动填好地址和模型。

填完点「测试连接」确认可用。

> **截图记账需要多模态模型**（能看图）。纯文本模型（如 deepseek-chat）可以用于 AI 助手对话，但无法识别截图。>   
> 推荐：`gpt-4o`、`qwen-vl-max`、`glm-4v`、`gemini-2.0-flash` 等。

## 功能一览

### 1. AI 截图记账

- 上传微信 / 支付宝 / 银行短信 / 外卖 / 购物订单截图，**可一次传多张**，也支持 `Ctrl+V` 粘贴
- AI 自动提取：金额、日期、时间、商户、收支方向、分类
- 识别结果可**逐条编辑**：改金额、改分类、改日期、切换收支类型、移除不要的
- **低置信度自动标记「待确认」**，重复记录标记「可能重复」
- 勾选确认后一键批量入账

### 2. AI 记账助手（对话）

- 「这个月钱花哪儿了？」「我预算还够吗」「分析下我的消费习惯」
- AI 拿到的是你**真实的账单数据摘要**（分类明细、趋势、目标进度）
- **流式输出**，像打字一样逐字显示
- 会主动指出异常消费、浪费点、环比变化

### 3. 省钱目标 + 督促

- 设定目标金额、已存金额、截止日期
- 进度条 + 剩余天数 + 达成提示
- 点「让 AI 给建议」，AI 会结合你的实际消费数据评估能否达成

### 4. 消费风格（防走极端）

设置你的偏好，AI 的说话方式会跟着调整：

- **偏节俭**：严格提醒克制，但不会让你省到影响生活
- **求平衡**：帮你找合理节奏（推荐）
- **较宽松**：温和提示，不过度施压

> AI 被明确要求：如果发现你**过度节省**（连续多日极低消费、砍掉必要开支），也要反过来提醒你照顾生活质量。

### 5. 总览与统计

- 首页：本月支出 / 收入 / 结余、预算进度、AI 洞察（一键生成）、按日分组的流水
- 统计图表：分类环形图、分类排行、收支趋势折线（月 / 年 / 自定义）
- 收支日历：月历视图，带收支圆点标记，点开某天看当天明细

### 6. 手机 / 电脑自适应

- **手机**：底部标签栏 + 悬浮「＋」按钮，单列卡片流，左右滑动友好
- **电脑**：≥900px 自动切换为**左侧边栏**布局，首页 / 统计 / 设置页变多栏，内容居中限宽
- 同一份代码，同一份数据，换设备打开自动适配

### 7. 界面与视觉

- 暗色主题 + 鼠尾草绿点缀，大圆角卡片
- **导航与操作全部使用线性 SVG 图标**（`js/icons.js`，统一 24px 网格 / 1.7 描边），不使用 emoji
- 分类图标（🍚 餐饮 / 🚇 交通 …）保留为可自定义的内容字段，不是装饰

### 8. 多账本

不同用途分开记（日常 / 旅行 / 装修），支持设置**每月起始日**（适配非 1 号发工资的情况）。

### 9. 预算

月度总预算 + 分类预算，首页显示剩余额度，超支标红。

### 10. 数据管理

- 导出 JSON 备份（可再导入还原）
- 导出 CSV 明细（Excel 可直接打开）
- 清空所有数据

## 隐私说明

- **所有账单数据存在浏览器的 localStorage 里**，不上传任何云端
- **AI 请求直接从你的浏览器发往你自己配置的服务商**，不经过任何中间方
- 图片会先在本地压缩（最长边 1400px）再发送，节省 token
- API Key 只存在本机，不会被上报

⚠️ **重要提醒**：清除浏览器数据、换浏览器或卸载会导致本地数据丢失。请定期用「导出备份」存一份 JSON。

## 目录结构

```
app/
├── index.html              入口页
├── manifest.webmanifest    PWA 配置（可安装到桌面）
├── sw.js                   Service Worker（离线缓存）
├── .nojekyll               GitHub Pages 用，阻止 Jekyll 处理
├── css/app.css             全部样式（设计令牌 + 组件 + 响应式）
├── icons/                  应用图标（PNG + SVG）
└── js/
    ├── icons.js            线性 SVG 图标库（34 个，统一 24px 网格）
    ├── store.js            数据层（账本/账单/分类/预算/目标/设置）
    ├── ui.js               Toast / 弹层 / 确认框 / Markdown
    ├── ai.js               AI 能力层（截图识别 + 对话 + 洞察）
    ├── charts.js           零依赖 SVG 图表 + 原创吉祥物
    ├── sheets.js           各类设置面板
    ├── pages-home.js       首页 / 记账表单 / 统计 / 日历
    ├── pages-shot.js       截图记账
    ├── pages-ai.js         AI 助手对话
    ├── pages-mine.js       我的 / 目标 / 搜索
    └── app.js              路由与主入口
```

## 开发者：本地测试

`_dev/` 目录下是一套**零依赖**的验证工具（不需要 npm install）：

```bash
cd _dev

# 数据层测试（52 项断言）
node test-logic.js

# UI 渲染测试（62 项断言，用 Node vm 模拟 DOM）
node test-ui.js

# 无头浏览器截图（验证真实渲染）
# 用法: node shot.js <url> <输出.png> [宽] [高] [等待ms] [actionsJson] [缩放]
node shot.js "http://127.0.0.1:8765/index.html" shot.png 1440 900 2400 "[]" 2

# 模拟 OpenAI 兼容接口（联调 AI 能力用）
node mock-ai.js        # 监听 127.0.0.1:8766
```

设计系统用的是 CSS 变量，改主题色只需要动 `app/css/app.css` 顶部的 `:root`。
